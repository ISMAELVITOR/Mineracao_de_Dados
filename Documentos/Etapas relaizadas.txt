Etapa 1 — Compreensão da base
✅ Nome da base escolhida.
✅ Domínio dos dados.
✅ Tabelas utilizadas.
✅ Principais entidades representadas.
✅ Quantidade de tabelas analisadas.
✅ Quantidade de registros.
✅ Quantidade de atributos.
✅ Tipos de atributos: numéricos, categóricos, textuais, temporais etc.
● Relacionamentos relevantes entre tabelas.
✅ Justificativa para a escolha das tabelas analisadas.


Etapa 2 — Preparação dos dados
Escolher os atributos que serão usados.
Verificar valores nulos.
Remover duplicatas (se houver).
Corrigir tipos de dados.
Padronizar textos.
Tratar variáveis categóricas.
Discretizar variáveis numéricas.
Criar atributos novos (se necessário).
Remover atributos desnecessários.
Transformar os dados para o formato de transações.

Etapa 3 — Análise exploratória (EDA)
Estatísticas descritivas.
Histogramas.
Boxplots.
Gráficos de barras.
Frequência das categorias.
Valores ausentes.
Matriz de correlação.
Identificação de outliers.
Discussão dos padrões encontrados.

Etapa 4 — Modelagem para regras de associação
Definir como cada transação será criada.
Escolher a estratégia:
por registro;
por entidade;
por discretização;
por junção entre tabelas.
Justificar a estratégia escolhida.

Etapa 5 — Extração das regras
Escolher o algoritmo (Apriori ou FP-Growth).
Definir suporte mínimo.
Definir confiança mínima.
Gerar todas as regras.
Calcular suporte e confiança.
Selecionar as regras mais relevantes.


Etapa 6 — Análise das regras
Para cada regra interessante:
Interpretar.
Dizer se é esperada ou surpreendente.
Avaliar suporte.
Avaliar confiança.
Explicar o padrão encontrado.
Identificar possíveis vieses.
Discutir se a regra realmente é útil.
